# IncluLearn AI

IncluLearn AI — Ayla AI арқылы оқу материалдарын инклюзивті форматтарға бейімдейтін Flask веб-сайты.

## Қосылған мүмкіндіктер

- Негізгі мәтіндер үлкейтілді.
- `A− / A / A+` қаріп өлшемін басқару батырмалары.
- Жоғары контраст режимі.
- Қараңғы режим.
- Интерактивті «Өзімді тексеру» тапсырмалары.
- Оқушы прогресін SQLite базасына сақтау.
- Материалдарды іздеу, ашу және өшіру.
- Материалды жаңадан бейімдеу үшін атау енгізу.
- Мобильді экранға бейімделген интерфейс.
- Қазақша, орысша және ағылшынша интерфейс тілін ауыстыру.
- Таңдалған тілдің браузерде сақталуы.
- PDF/DOCX/PPTX/TXT/MD/CSV/HTML файлдарын оқу.

## Іске қосу

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Сайт `http://localhost:3000` адресінде ашылады.

## Қосымша AI режимі

API кілті берілмесе де, сайттың жергілікті бейімдеу режимі жұмыс істейді. AI режимін қосу үшін орта айнымалыларын орнатыңыз:

```bash
export OPENAI_API_KEY="..."
export OPENAI_MODEL="gpt-4o-mini"
```

API кілтін кодқа тікелей жазбаңыз.
